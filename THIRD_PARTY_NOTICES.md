# Third-party notices (kiln)

kiln is MIT-licensed (see [LICENSE](LICENSE)). This file names the software kiln depends on or drives and the
licence each one declares. It is a record for users and contributors, not legal advice: each project's own
licence text is the authority.

## Python packages pip installs with kiln

None of these is copied into this repository; pip installs them from their own releases. The tables are
generated by `tools/gen_notices.py` from the installed packages' metadata (through `pip-licenses`), so the
licence strings are the ones each package declares. Regenerate them in the same pull request that changes a
dependency. CI's licence gate refuses any installed package whose licence string is not on the reviewed list in
`.github/workflows/ci.yml`; `tests/test_licence_gate.py` proves that it does.

## Programs kiln drives but does not include

- **kohya-ss sd-scripts** (Apache-2.0): the trainer. The training runtime installer (planned) clones it at tag
  v0.12.3, commit `cb70b96858477e716a2096292ab8aab433277f38`, into your kiln home and installs it into its own
  virtual environment from [runtime/train.lock.txt](runtime/train.lock.txt). It is never vendored here. When
  the low-memory training wrappers ship, each one carries an Apache-2.0 attribution header naming the upstream
  file and lines it adapts.
- **The trainer's own dependencies** (PyTorch, accelerate, transformers, diffusers, bitsandbytes and the rest
  of `runtime/train.lock.txt`): installed into that separate environment under their own licences. They are
  not dependencies of the kiln package and are not covered by the tables above.
- **ComfyUI** (GPL-3.0): evaluation renders go to a ComfyUI server over its HTTP API. kiln never imports,
  vendors or copies ComfyUI code; the pinned versions live in easel's `runtime/comfyui.lock.json`.

## Optional extras (off unless you install them)

- **NudeNet** (AGPL-3.0), for the optional image screens (planned, behind an explicit licence acceptance): it is
  installed into a separate environment under your kiln home and called as a subprocess through a worker
  script written from a plain-text template, with JSON over stdin and stdout. kiln never imports it, and
  `tests/test_no_agpl_imports.py` asserts that nothing under `src/` imports it or ultralytics.
- **dghs-imgutils** (MIT), pinned `==0.19.0`, for the optional identity score (planned `[identity]` extra). The
  CCIP model it downloads has a licence that is unknown at the time of writing (2026-11): kiln prints the model
  card's address and records `licence: {status: unknown}` until a person has read it.

## Data that is not shipped

- No model weights, images or datasets are included. Test images are generated at test time.
- Base-model licences are summarised per family in `families/*.yaml` (`licence_summary`, with the source URL);
  the summary is a pointer to the licence, not a substitute for reading it.
